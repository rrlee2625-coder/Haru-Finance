# Haru 🩷 우리집 가계부

하은 & 루리 커플을 위한 공동 가계부 웹앱입니다. 별도 설치나 빌드 과정 없이 `index.html` 파일 하나로 동작하며, Firebase Firestore를 통해 실시간으로 데이터를 공유합니다.

🔗 **접속 주소**: https://rrlee2625-coder.github.io/Haru-Finance/

## 주요 기능

- **현황 대시보드**: 이번 달 수입/지출/투자 현황과 연간 누적 통계를 한눈에 확인
- **수입 내역**: 고정 수입 + 추가 수입(야근수당 등) 관리, 카테고리별 분류
- **지출 및 고정비**: 하은/루리/공통으로 구분된 지출 내역을 고정비·추가지출로 나누어 표시
- **고정비 관리**: 매월 자동으로 반영되는 고정비 템플릿을 등록/수정, 월별 미반영 항목 자동 감지 및 복구
- **투자 포트폴리오**: 계좌/종목별 투자 내역 및 월별 투자금 기록 (기본값 대신 해당 월 값으로 대체 가능)
- **개인 가계부**: 하은/루리 각자의 수입-지출 상세 내역을 한 곳에서 확인 (접기/펼치기)
- **코멘트(채팅)**: 가계부 관련 메모를 날짜별로 남길 수 있는 간단한 채팅 탭
- 모든 금액 입력란에 실시간 콤마(,) 포맷팅 적용
- 모바일 화면에 최적화된 반응형 테이블 레이아웃

## 기술 스택

- Vanilla JavaScript (빌드 도구 없음)
- Tailwind CSS (CDN)
- Firebase Firestore (compat SDK, 실시간 동기화)
- Chart.js, Lucide Icons

## 사용 방법

1. `index.html`을 웹 서버에 업로드하거나 그대로 브라우저에서 엽니다.
2. Firebase 프로젝트의 Firestore를 사용하도록 `firebaseConfig` 값이 파일 내에 이미 설정되어 있습니다. 다른 Firebase 프로젝트를 쓰려면 `index.html` 내 `firebaseConfig` 객체를 본인 프로젝트 값으로 교체하세요.
3. 처음 접속 시 "누구세요?" 모달에서 하은/루리 중 본인을 선택하면, 이후 기기에 저장되어 코멘트 등에 자동으로 반영됩니다.

## 데이터 구조 (Firestore)

- `finance_monthly/{YYYY-MM}`: 월별 수입/지출/투자 데이터
- `finance_monthly/_recurring`: 매월 자동 반영되는 고정비 템플릿
- `finance_meta/categories`: 카테고리 드롭다운에 사용되는 공용 카테고리 목록
- `chat_messages`: 코멘트(채팅) 탭 메시지
